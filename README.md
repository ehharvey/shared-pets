# # Shared pets (working title)
This is a project for a shared-pets app. The high-level is a social oriented habit tracker where habits are performed that translate as 'care acts' to a pet.

# Requirements and Goals
1. iOS (iPhone) app mandatory; iOS iPad, macOS, apple watch optional
2. Track habits on various recurrances (recurrances TBD) mandatory
3. Pet visualizatons with care actions mandatory. First pet type is Shih Tzu mandatory
4. Social mechanics (ie "shared raising") to motivate individuals to perform habit behaviours. (this needs refining)
5. Minimal infra costs

# Prior Art
1. Tamagotchis
2. Habit RPG
3. Facebook 'pokes'
